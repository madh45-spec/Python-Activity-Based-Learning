# Python Activity-Based Learning

## About This Repository

This repository contains 10 Python case study projects developed as part of the Activity-Based Learning assignment.

Each project focuses on solving a practical problem using fundamental Python programming concepts, computational thinking, and logical problem-solving techniques.

## Case Studies

| No. | Case Study |
|---|---|
| 01 | University Scholarship Allocation |
| 02 | Progressive Electricity Billing |
| 03 | Warehouse Inventory Reconciliation |
| 04 | Student Performance Trend Analysis |
| 05 | Student Timetable Conflict Detection |
| 06 | Student Marks Matrix Analysis |
| 07 | Tuple-Based Transaction Audit |
| 08 | Student Academic Risk Classification |
| 09 | Multi-Criteria Internship Candidate Ranking |
| 10 | Smart Campus Incident and Maintenance Prioritization |
