# Python Activity-Based Learning

## About the Project

This repository contains 10 Python case studies developed as part of the Activity-Based Learning assignment.

The projects demonstrate fundamental Python programming concepts through practical problem-solving activities.

## Case Studies

1. University Scholarship Allocation
2. Progressive Electricity Billing
3. Warehouse Inventory Reconciliation
4. Student Performance Trend Analysis
5. Student Timetable Conflict Detection
6. Student Marks Matrix Analysis
7. Tuple-Based Transaction Audit
8. Student Academic Risk Classification
9. Multi-Criteria Internship Candidate Ranking
10. Smart Campus Incident and Maintenance Prioritization

## Technologies Used

- Python 3
- Visual Studio Code
- Git and GitHub

## Concepts Covered

- Variables and Data Types
- Operators
- Conditional Statements
- Loops
- Strings
- Lists and Nested Lists
- Tuples and Tuple Operations
- Sorting
- Algorithms and Pseudocode
- Problem-Solving Techniques
